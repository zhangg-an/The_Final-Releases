The Final Windows x64 便携版

一、下载安装
1. 在 GitHub Releases 页面打开标记为 Latest 的最新版。
2. 下载 TheFinal-<版本号>-Windows-x64.zip。
3. 完整解压 ZIP，不要直接在压缩包内运行。
4. 保留解压后的整个文件夹，不要只复制 TheFinal.exe；程序运行库位于同一文件夹中。
5. 双击 TheFinal.exe，稍候应用会在默认浏览器打开。

二、运行环境
1. 支持 Windows 10/11 x64。
2. 电脑需要安装 Google Chrome，并保持网络可用。
3. 无需另外安装 Python、Node.js、Redis 或 Docker。
4. 请将程序放在桌面或“文档”等当前用户有写入权限的位置，不要放入 Program Files。
5. 如果 8000 端口已被其他程序占用，请先退出占用该端口的程序。

三、账号与数据
1. 店小秘和 GIGA 第一次使用时，需要由使用者本人在弹出的 Chrome 窗口中完成安全登录。
2. 发布、改价、下架和收藏功能只能操作使用者本人已授权的店铺及平台账号。
3. 交付包不包含开发者的账号、密码、Cookie、登录状态、上传表格或历史任务。
4. 本地应用数据保存在程序目录的 data 文件夹。

四、升级
1. 升级前退出旧版本。
2. 备份旧版本中的 data 文件夹。
3. 从 Releases 页面下载新的 Latest 版本并完整解压。
4. 不要直接用新文件覆盖正在运行的旧程序。
5. 需要保留本地数据时，再按版本说明迁移 data 文件夹。

五、校验与系统提示
1. Release 同时提供 SHA-256 校验文件，可用于确认下载文件完整。
2. Windows SmartScreen 可能提示未知发布者；当前程序尚未进行商业代码签名。
3. 只有在下载来源和 SHA-256 均确认无误时，才选择“更多信息”并运行。
